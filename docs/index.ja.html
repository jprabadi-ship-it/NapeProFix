できること

Hammerspoon も Karabiner も使いません。アプリ単体で完結します。

4方向に好きな動作を割り当て

ジェスチャの上下左右それぞれに、組み込み動作または任意のキーボードショートカットを設定できます。

レイヤー 0〜7

8つの割り当てセットを切り替えて使えます。切り替えはメニューからでも、自分で登録したショートカットからでも行えます。

回転補正

オクタシフトの設定がリセットされて向きがズレても、メニューから90°刻みで戻せます。デバイスを設定し直す必要はありません。

スクロールモードにも割り当て

ボールスクロール中の転がし方向にも動作を割り当てられます。割り当てない方向は、回転量に比例したデバイス本来の滑らかなスクロールをそのまま通します。上下はスクロールのまま、左右だけデスクトップ切り替え、といった組み方ができます。

加速するスクロール

ジェスチャのスクロールは、続けて転がすほど量が増えます。行単位と、転がす速さに応じてピクセル単位で伸ばす方式を選べます。向きが合わなければ反転スイッチで直せます。

クリック位置がずれない

トラックボールは指がボタンを押す・離す瞬間にボールがわずかに回り、狙った場所から数ピクセルずれてクリックされます。押している間カーソルを止め、離したあと元の位置に戻します。ドラッグは妨げません。

ログイン時に起動

設定を1つ入れるだけで、Mac を起動するたびに自動で常駐します。

設定手順を内蔵

Keychron Launcher 側で何を設定すべきかを、アプリのメニューからいつでも図付きで確認できます。初回起動時にも自動で表示されます。

使い始めるまで

Keychron Launcher 側の設定が2つ必要です。アプリの「動かないとき / Launcher の設定…」から同じ内容をいつでも確認できます。

1. ジェスチャーモードを常時有効にする

アドバンスモード > 「常にジェスチャーモードを有効にする」をオンにしてください。オフのままだと、「ボールジェスチャ」を割り当てたボタンを押している間しかジェスチャが発火しません。

2. 4方向にキーを割り当てる

修飾キーを付けずに、以下のとおり割り当ててください。

方向通常キーmacOS
上Print Screenf13
下÷（テンキー）pad/
左Num Lockpadclear
右Inserthelp

Launcher が Num Lock を Num<br/>Lock と表示することがありますが、これは Launcher 側の表示上の不具合です。設定内容としては正しいので、そのままで問題ありません。

3. アクセシビリティ権限を許可する

初回起動時に求められます。許可すると数秒で自動的に有効になり、アプリを再起動する必要はありません。

知っておくと困らないこと

なぜ修飾キーを使ってはいけないのか

Launcher で修飾キーを付けると、ジェスチャ1回ごとにその修飾キーが完全に押されて離されます。連続で転がすと Option 連打のような状態になり、アプリ側が誤反応します。

これはアプリ側では対処できません。flagsChanged は文字キーより先に届くため、届いた時点ではジェスチャの一部か通常のキー入力かを判別できず、デバイスの識別も不可能です。上記の4キーは Mac のキーボードに存在せず、素で押しても何も起きないため、修飾キーなしで安全に使えます。

Pause と Scroll Lock は使えません

Pause は macOS でキーコードを持たず、イベントごと消えます。Scroll Lock は F14 になり、旧 Mac キーボードの輝度ダウンとしてシステムが低レイヤーで消費するため、どのアプリも横取りできません。

レイヤー切替キーの選び方

このアプリは入力元のデバイスを区別できません。イベントタップにデバイス情報が乗らないためです。登録したキーはキーボードから直接押しても同じ動作になり、そのキーは他のアプリからは使えなくなります。

つまり「システム全体で犠牲にしていいキー」を選ぶ必要があります。テンキー系（× など）はテンキー付きの Mac で衝突し、⌃⌥ + 英字は他アプリのショートカットと衝突しうる、という選択になります。

なお「修飾キーを付けるとジェスチャ1回ごとに押されて離される」問題は、転がすたびに連続発火するジェスチャ固有のものです。ボタンの押下は1回きりなので、レイヤー切替には修飾キー付きの組み合わせを使って構いません。

Launcher を初期化したときの復旧

初期化するとジェスチャのキー割り当てが消えますが、オクタシフトの回転設定も既定値に戻ります。キーだけ入れ直すと向きがズレたままになります。

回転はデバイス側とアプリ側の両方にあるため、片方だけ変えると必ずズレます。キーを入れ直したあと、アプリのメニューで「0°に戻す」、それでもズレていれば「90°回す」で合わせてください。

別の Mac に持っていくと Gatekeeper に止められます

公証していないためです。macOS 15 以降は右クリック →「開く」では回避できません。システム設定 → プライバシーとセキュリティ を開き、下部に出る「このまま開く」を押してください。
